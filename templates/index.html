Understanding the Confusion Matrix

Evaluated on 20,000 completely untouched test transactions:

  • True Positives (73): Fraudulent transactions correctly caught and flagged.
  • False Positives (21): Legitimate transactions incorrectly flagged (only 21 false alarms out of 19,884 genuine transactions!).
  • False Negatives (43): Fraudulent transactions that slipped through the threshold.
  • True Negatives (19,863): Legitimate transactions cleared smoothly.

About This Project

Problem Statement

Credit card fraud causes tens of billions in annual losses across global banking systems. A major challenge in automated fraud detection is the extreme rarity of fraudulent events (typically less than 1% of transactions). Standard machine learning models trained with traditional accuracy objectives struggle because predicting the majority class yields deceptively high accuracy while missing devastating fraud occurrences.

Ensemble Machine Learning Approach

Ensemble learning addresses class imbalance and variance by combining multiple specialized algorithms. In this project, we compared 8 diverse classifiers: Logistic Regression, Decision Tree, Random Forest, Extra Trees, Gradient Boosting, HistGradientBoosting, Soft Voting, and Stacking. Gradient Boosting and Tree Ensembles achieved superior resilience and precision.

Engineering & Pipeline Design

  • Zero Data Leakage: Preprocessing pipelines (imputation, robust scaling, one-hot encoding) are strictly fit on training data only.
  • Threshold Optimization: Decision threshold was optimized on a dedicated validation split to maximize F1-score rather than assuming 0.50.
  • Clean Production Pipeline: Feature engineering and inference are packaged into an end-to-end scikit-learn Pipeline saved via Joblib.

Project Metadata

Dataset: Credit Card Transactions (1,296,675 rows)
Target: is_fraud (0 = Legit, 1 = Fraud)
Saved Model: models/fraud_detection_model.joblib
Backend: Python / Flask 3.1
